# 智安校园：校园设施安全协同核查智能体

版本日期：2026-10-21。申报方向：管理服务 / 校园安全。

关键词：校园安全、证据核查、智能体、数字孪生、协同处置。

## 作品概要

面向校园工程训练中心和后勤保障楼，围绕设施异常与区域人员作业，提供“观测 - 核查 - 人工确认 - 维修 - 独立复核”的协同工作台。自然语言问题先解析设备与意图，再从后台读取带来源和时间的观测、候选连接、人员位置、作业计划与工单；自由输入由 DeepSeek 分类，匹配模板则按本地工具结果回答，不匹配则由 DeepSeek 回答当前问题；快捷模板入口直接执行本地核查。模型不直接控制设备，也不能绕过岗位权限。

## 核心痛点与解决方法

1. 设施、人员和作业信息分散：同一编号连接三维定位、GIS、台账、观测和处置记录。
2. 状态查询与故障影响容易混淆：状态只报告有效观测及判断依据；影响按故障假设查询候选连接，区分供电、流体和空间关联。
3. 通用模型容易虚构现场信息：读数和业务动作由后台提供；展示核查依据与实际执行记录；过期和缺失数据不判为正常。
4. 处置过程难追踪：核查草案需人工确认，维修人与复核账号分离，版本冲突或权限不满足时拒绝操作。

## 核心场景

B-05 校园排水泵组出现异常观测。校园安全员查询状态，继续核查排水管路、供电关联、区域人员及作业时段，准备草案后指派维修账号。维修员提交处理凭证，另一复核账号审核关闭或退回。

在设计场景中，若泵组承担相关楼宇排水且备用能力不足，应核查排水保障和场地使用安排。系统不会直接推断停课、积水、人员伤害或上游电柜损坏。实际服务范围、备用泵、管路、隔离状态和现场记录是后续接入必须提供的依据。

## 已实现能力

- 三维外观、A/B 区域、剖面和第一人称巡视；室内外人员与移动车辆演示。
- GIS 卫星参考、平面和三维外观；区域进入告警、测距、图层与观测导入。
- 设备编号、大小写、全角、连字符及常用名称识别；歧义时追问。
- 状态、候选影响、人员作业、责任记录和复核建议分意图回答。
- 实际工具执行记录；后端密钥配置；模型异常时显示本地核查回退。
- 草案确认、维修指派、处理凭证、独立复核、作业冲突检查及履历。
- 历史回放、模拟能耗分析、六类岗位权限和隔离演示空间。

## 数据与应用范围

本版是可运行的校园业务原型。设备、人员、告警和关联台账为设计模拟，不是浙江大学实际设施、人员信息或业务系统接入证明。三维保留既有工程建筑，作为工程训练中心与后勤楼的示意模型。

GIS 卫星底图沿用公开工业地块作为布局参考；地块来源名称和许可保留，不将它称为学校实测地图。默认供电和排水连接均为带类型、方向及条件的候选台账，未标为现场核验。工程测试阈值仅验证软件分支。

## 验证与预期成效

自动测试用于核查程序行为，浏览器操作用于核查界面主线。测试数量和结果以同版本验证记录为准，不能替代现场试用或证明效率提升。

预期减少跨页面查找和口头转述，提高来源可追溯性及处置记录完整性。建议由获授权的校园岗位使用脱敏数据开展对照任务，记录首次正确完成率、完成时间、错误类型和闭环完整率；结果在实际试验后填写，不预设提升百分比。
