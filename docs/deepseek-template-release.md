# DeepSeek 模板路由验收记录

日期：2026-10-21。

## 当前行为

- 自由输入：DeepSeek 通过 JSON 输出识别是否匹配校园核查模板及具体意图。
- 匹配模板：后台读取当前观测、候选连接、人员作业和工单，本地模板生成回答；不再调用模型改写模板事实。
- 非模板：DeepSeek 回答当前问题；本策略不传后台快照或历史模板回复。
- 快捷按钮：直接执行本地模板，不消耗模型分类或生成调用。
- 状态与故障影响分开；大小写、全角、空白和多种连字符统一识别设备编号。
- 模型失败时实际记录显示回退；不把未执行的模型识别标成成功。草案仍需人工确认，模型分类不能凭空创建任务。

## 验证

- 完整后端：270项测试及47项子测试通过，3条第三方弃用警告。
- 前端：69项测试通过。
- 官方API真实连接：仅发送固定合成问题；全角小写状态问题识别为status，故障影响识别为impact，雨污分流原理识别为非模板并成功生成回答。
- 本地浏览器主线：模板核查、草案生成和维修页面跳转验证；实际业务数据不用于外部连接测试。
- 单元测试覆盖：模板查询只调用分类、非模板分类后生成、模板历史不外传、否定派单、模型误判草案、分类失败回退和跨供应商密钥隔离。

## 配置与交付边界

本机密钥保存在 `.local/model.dpapi`，由当前Windows用户加密，Git和Docker均排除该目录。云部署需要本人在平台后台配置 DEEPSEEK_API_KEY；本机文件不能直接用于Linux云服务器。新仓库包含程序、部署配置、测试与文档，推送源码不等于已完成公网部署或参赛视频制作。
